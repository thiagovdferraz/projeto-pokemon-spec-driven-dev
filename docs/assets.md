# Asset Organization Guide

**Project**: Pokémon TCG 151 — Booster Pack Opening Game
**Constitution gate**: Principle V — Disk-Organized Assets

---

## Directory Structure

```
assets/
├── index.json              # Card manifest (auto-generated by download_cards.py)
├── 01_comum/               # Common cards
├── 02_incomum/             # Uncommon cards
├── 03_raras/               # Rare + Rare Holo cards
├── 04_duplo_raras/         # Double Rare / Rare Ultra / Rare Holo EX/GX/V/VMAX
├── 05_arte_secreta/        # Illustration Rare cards
├── 06_duplo_arte_secreta/  # Special Illustration Rare / Rare Rainbow / Rare Secret
└── 07_legendaria/          # Hyper Rare cards
```

---

## Naming Convention

### Card images

`<card-id>.jpg`

- `card-id`: The unique identifier returned by the `pokemontcg.io` API (e.g., `sv3pt5-1`).
- Format: `.jpg` only. No `.png`, `.webp`, or other formats.
- Case: lowercase, as returned by the API.

**Examples**:
```
assets/01_comum/sv3pt5-1.jpg       # Bulbasaur
assets/03_raras/sv3pt5-50.jpg      # Venusaur
assets/07_legendaria/sv3pt5-207.jpg
```

### Manifest file

`assets/index.json` — generated by `download_cards.py`. Do not edit manually.

## Rules

1. **No base64 inline assets** in JS or CSS files (images > 1 KB).
2. **No raw string paths** in JS — always import or use the `imagePath` field from `index.json`.
3. **Re-running** `download_cards.py` is safe — existing `.jpg` files are skipped.
4. **Manual additions** to asset folders must also be added to `index.json` manually, or the manifest must be regenerated.
